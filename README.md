# not-free

![License](https://img.shields.io/badge/license-MIT-green)

תוכנת פראנק בעברית שמתחזה לכלי AI לעקיפת סינון נטפרי — ובסוף חושפת: *"עבדנו עליך..."*

> **התוכנה לא עושה כלום.** אין שינוי הגדרות, אין נגיעה בקבצים, ולא נשלח שום מידע לשום מקום.
> כל הפראנק הוא הדמיה מקומית.
>
> היציאה היחידה לרשת היא **בדיקת עדכון**: בהפעלה נשאלת שאלה אחת מול גיטהאב — מה מספר
> הגרסה האחרונה. אין הורדה ואין דיווח. בלי חיבור, הבדיקה נכשלת בשקט והתוכנה עובדת רגיל.

## איך זה בנוי

חלון נייטיב (WebView2, המנוע של Edge שכבר מותקן בכל Windows) שמציג ממשק HTML מקומי.
פייתון הוא רק מארח: פותח את החלון וחושף את מה שדפדפן לא יכול לעשות לבד — קריאת הלוח,
בדיקת הגרסה וסגירת התוכנה. כל הלוגיקה יושבת ב-JS.

הממשק עצמו חסום לרשת ב-CSP, ונשאר חסום: בדיקת העדכון רצה בפייתון, לא בדפדפן.

## הזרימה

```
welcome → survey → analysis → rejection | request → hacking → outcome → exposure
```

מסך פתיחה → שאלון (סטטוס / השקפה / צורך / עדה) → חישוב ניקוד → אישור או דחייה →
הזנת קישור ונימוק → "פריצה" בטרמינל → כישלון → בחירה בין חזרה לסינון להמשך → החשיפה.

## הפעלה

```bash
pip install -r requirements.txt
python main.py
```

לעריכת הממשק בלבד אפשר לפתוח את `ui/index.html` ישירות בדפדפן — הכל יעבוד חוץ
מכפתור ההדבקה וכפתורי הסגירה, שדורשים את המארח.

## בנייה ל-EXE

```bash
build.bat
```

## מבנה

| נתיב | תיאור |
|---|---|
| `main.py` | נקודת הכניסה |
| `not_free/host.py` | חלון WebView2 והגשר ל-JS |
| `not_free/clipboard.py` | קריאת הלוח דרך Win32 |
| `not_free/updater.py` | בדיקת גרסה מול גיטהאב — היציאה היחידה לרשת |
| `not_free/resources.py` | נתיבים לקבצי הממשק |
| `ui/index.html` | שלד הדף |
| `ui/css/base.css` | טוקנים, כולל סולם התנועה של כל האנימציות |
| `ui/css/` | רכיבים ואנימציות |
| `ui/js/scoring.js` | אפשרויות השאלון והמשקלים — מקור אמת יחיד |
| `ui/js/screens/` | מסך לכל שלב בזרימה |
| `tools/make_icon.py` | מחולל `GH.ico` — מגן נטפרי מנופץ, שבעה גדלים |
| `not-free.spec`, `version_info.txt` | אריזה ל-EXE |
| `docs/תרחישים.xlsx` | טבלת הניקוד (מסמך עיצוב) |
| `docs/הוראות.txt` | מטלות ורעיונות להמשך |
